这是实验的Readme文件：Shell实验
你也可以通过下载WSL之后，用VScode 安装WSL插件，打开Terminal运行下面的代码，获取全部的文件，自己运行、试着完成这个实验

完成任何一个确定性目标的最高效方式，就是盯准目标，走直线。
解题也是如此。为了完成Shell实验，我们务必先要弄清楚自己的起点在哪里，目标是什么。通过Readme.md(名字都告诉你了，求求你阅读我!(Readme!))

我们先理清楚，这么大一个shelllab的文件夹里有哪些文件，他们分别负责做什么、有什么关系，过程中，我先会介绍一些相关的重要概念、专业名词。

文件名中的概念

文件名 对应英文 功能
Readme.md Readme Markdown .md是用Markdown语法表示排版的纯文本文件,Readme表示该文件是一个对整体所有文件的内容、架构说明，最重要！
.gitignore git ignore 是告诉版本管理工具Git，在管理时候忽略一些文件的文件，与实验无关，不用管。
Makefile make file 是告诉make工具读取的自动化命令清单，常用于自动编译、测试、清理和管理程序项目，也不用管，Readme会告诉我们用法
.c后缀文件 用C语言写的代码文件。可以被编译器编译成CPU可以理解执行的文件。编译后的文件会去掉.c。如：tsh.c--编译-->tsh，运行./tsh就能执行tsh文件
.pl后缀文件 Perl 用Perl语言写的代码文件，可以被解释器解释、执行的脚本文件。已经安装解释器Perl、文件指定后可以直接执行,运行./sdriver.pl
.txt后缀文件 text 内容就是纯文字
.out后缀 output 常常是软件、程序的输出结果。
