1F · 2026-08-03 · 约 4 分钟

题型一、森林的遍历

知识点：

1、森林：m(m≥0)棵互不相交的树的集合
2、森林的遍历：从左到右、按照树的遍历方式访问森林中的每一个结点，使得每一个结点都仅被访问一次的访问方式。
3、树的遍历方式：从左到右，根据“根”被访问的先后顺序分类，共四种

a.前序遍历(先序遍历)：根-左-右
b.中序遍历：左-根-右
c.后序遍历：左-右-根
d.层序遍历：按照从上到下，从左到右的层的次序访问每一个结点

4、前、后序遍历的序列具有“可裁性”，即其中的局部仍然是子树的前、后序列。

解题关键

1、学会根据一棵树的前序序列和后序序列，确定这棵树的方法，再推广到森林。

思路如下：

1、前序序列的第一个结点一定是树的根(A)，也是后序序列的最后一个结点
2、看前序序列，根之后的第一个顶点，一定是第一子树的根。(B)
3、看后序序列，根(B)之前，到(上一棵子树或开头)截止的序列(DEB)，是第一子树的后序序列
4、由[3]确定出来了第一子树的后序序列，可以判断出来该子树的所有结点构成(也就是有
哪些字母)，从而，也可以同时确定该子树的前序序列(BDE)。
于是，我们确定了以B为根节点的子树，它的前序序列是BDE，后序序列是DEB。
5、继续看原来的前序序列，排除掉第一子树(BDE)之后的下一个顶点，一定是第二子树的根。(C)
…………以此类推
以上过程，
我们已知：①树的根、②前序序列、③后序序列，
推理出来了：树的所有①子树的根、②子树的前序序列、③子树的后序序列，
从而问题变成了：已知子树的前序序列、后序序列，确定该子树的问题。
子树确定了，原树就确定了。

递归

将这里的子树，看成一颗全新的完整的树
我们就将原来的大问题，转化成了更小的、和原问题一模一样的问题：
“已知前序+后序，确定树的结构”
我们按照如上的推理方法、可以无限重复下去，直到：最小的树只剩下了一个结点，我们就确定完成了这棵树，从而，每一棵树都能确定。

解决问题的过程，又调用了同一个过程本身，让问题越来越小，这就是递归的思想。

题型二、栈相关知识点：入、出栈的语句、栈满的条件

知识点：

1、栈是一种仅能在表尾插入或删除元素的线性表，其中表尾称作：栈顶，表头称作：栈底
2、栈顶指针：存储了栈顶的地址的指针
2、线性表是n个元素的有限序列。
3、我们可以用这样一幅图来形象理解栈的结构：

4、数组空间中，下标与对应空间中存储的元素一一对应

解题思路：

1、先画出该数组空间，标出两个栈的栈底、栈顶、空间中的位置序号
2、于是对于栈1而言，要想入栈(在栈顶添加一个元素x)，就需要做两步：
1️⃣栈顶位置向生长方向移动一个单位。(对应栈指针Top1++)
2️⃣将x存入栈顶地址对应空间内。(对应SPACE[TOP1] = x)
两条可以合并起来：
SPACE[++TOP1] = x
出栈(取出当前栈顶的元素，存入x)：
1️⃣将栈顶位置的元素记录下来x = SPACE[TOP1] 2️⃣将栈顶位置向栈底回退一个单位：TOP1--也可以合并：x = SPACE[TOP1--] 栈2同理，于是得到(1)的答案 ![[Pasted image 20260809133841.png]] 由于两个栈生长方向是相冲突的，为了避免覆盖的情况， 栈满条件就是两个栈的栈顶碰面：TOP1 + 1 == TOP2此时，任一个栈，都不能继续添加元素，否则立刻会出现覆盖的情况。 栈空条件则是栈里什么都没有的情况。 栈顶要在栈底位置还要之前， 所以对于栈1空：TOP1 == -1栈2空：sTOP2 == n`
这两个位置在SPACE中都不存在。

为什么不是TOP1 == 0 ?

因为，此时栈顶、栈底重合，栈中仍然存在一个元素：TOP1 == 0，没有完全空。
