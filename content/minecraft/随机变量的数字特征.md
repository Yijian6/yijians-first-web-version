## 数学期望 【E(X)】——反映预期
：随机变量取值的==加权平均==，权重就是概率。
### **公式：**
- 离散型：E(X) = Σ xᵢ·pᵢ
- 连续型：E(X) = ∫ x·f(x) dx （从 −∞ 到 +∞）
### **性质：**
- E(C) = C （常数的期望是自身）
- E(aX + b) = aE(X) + b （线性性）
- E(X + Y) = E(X) + E(Y) （**无条件成立**，不需要独立！）
- X、Y **独立**时：E(XY) = E(X)·E(Y)
### **考点：**
求函数 g(X) 的期望，直接用 $E[g(X)] = ∫ g(x)·f(x) dx$，**不需要先求 g(X) 的分布**。

## 方差【D(X)】——反应离散程度
**：** X 偏离其均值的平方的==期望==。(本质也是一个期望：$D(X) = E\{[X − E(X)]²\}$)
### **公式：**
- 定义式：D(X) = E{[X − E(X)]²}
- **计算式（考试用这个）：D(X) = E(X²) − [E(X)]²**
#### 记忆："平方的期望" 减 "期望的平方"
### **性质：**
- D(C) = 0
- D(aX + b) = a²D(X) （**常数 b 不影响方差，a 要平方**）
- X、Y **独立**时：D(X ± Y) = D(X) + D(Y) （注意：减也是加！）
- D(X) ≥ 0，D(X) = 0 ⟺ P(X = C) = 1
### **陷阱：** 
D(X+Y) = D(X) + D(Y) + 2Cov(X,Y)。不独立时**不能丢掉协方差项**，这是大题常见扣分点。

## 协方差【Cov(X,Y)】
:X 和 Y 各自偏离均值后乘积的期望。
### **公式：**
- 定义式：$Cov(X,Y) = E\{[X−E(X)][Y−E(Y)]\}$
- **计算式：Cov(X,Y) = E(XY) − E(X)·E(Y)**
### **性质：**
- Cov(X,X) = D(X)
- Cov(X,Y) = Cov(Y,X)
- Cov(aX, bY) = ab·Cov(X,Y)
- Cov(X₁+X₂, Y) = Cov(X₁,Y) + Cov(X₂,Y) （**可拆分**）
- X、Y 独立 ⟹ Cov(X,Y) = 0 （**反过来不成立！**）
### **考点：**
给联合分布或联合密度，求 Cov。套路就是分别算 E(X)、E(Y)、E(XY)，代入计算式。
## 相关系数——==反映线性相关程度==
**：** 把==协方差==除以两个标准差，消除量纲。

### **公式：**
$ρ(X,Y) = \frac {Cov(X,Y)}  {√[D(X)·D(Y)]}$
### **性质：**
- −1 ≤ ρ ≤ 1
- |ρ| = 1 ⟺ X 与 Y 之间有**线性关系** Y = aX + b
- ρ = 0 称为"不相关"
