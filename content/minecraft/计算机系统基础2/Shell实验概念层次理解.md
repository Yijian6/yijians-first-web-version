##  文件名中的概念

| 文件名          | 对应英文            | 功能                                                                                    |
| ------------ | --------------- | ------------------------------------------------------------------------------------- |
| `Readme.md`  | Readme Markdown | .md是用Markdown语法表示排版的纯文本文件,Readme表示该文件是一个对整体所有文件的内容、架构说明，最重要！                          |
| `.gitignore` | git ignore      | 是告诉**版本管理工具Git**，在管理时候**忽略**一些文件的文件，与实验无关，不用管。                                        |
| `Makefile`   | make file       | 是告诉`make`工具读取的**自动化命令清单**，常用于**自动编译**、**测试**、**清理**和管理程序项目，也不用管，Readme会告诉我们用法         |
| `.c后缀`       |                 | 用C语言写的代码文件。可以被编译器编译成CPU可以理解执行的文件。编译后的文件会去掉.c。如：`tsh.c--编译-->tsh`，运行`./tsh`就能执行`tsh`文件 |
| `.pl后缀`      | Perl            | 用Perl语言写的代码文件，可以被解释器解释、执行的脚本文件。已经安装解释器Perl、文件指定后可以直接执行,运行`./sdriver.pl`               |
| `.txt后缀`     | text            | 内容就是纯文字                                                                               |
| `.out后缀`     | output          | 常常是软件、程序的输出结果。                                                                        |
|              |                 |                                                                                       |
