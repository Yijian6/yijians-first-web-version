# 券商
：帮人 **买卖**==**证券**== 的金融机构。
(因为交易所只和==券商==打交道，我们不能直接在交易所开户买卖，只能通过券商。
==券商也借此盈利==)
## 证券：
：证明你有某种权利的凭证。这种凭证可以买卖。
>就像是：你有一张优惠券，对应的权利是，买东西便宜。这张优惠券本身你也可以卖给别人。股票则是一个公司所有权的凭证，你也可以买卖它。
### 常见的证券包括:
	1️⃣股票
	2️⃣基金
	3️⃣债券
	4️⃣衍生品：期权、权证、期货
	5️⃣其他：……

### 券商的职责
- 开户和身份核验（反洗钱要求）
- 保管你的资金和股票
- 结算交收，保证钱和股票按时到位
- 风控，例如检查你账户里有没有足够的钱
- 提供融资（打新常用的“孖展”）和行情工具
### **券商的盈利方式**：0
🔥1️⃣==**佣金**==  ：每买卖一次 **股票**，券商从中抽取佣金。
🔥2️⃣==**平台费**==：每买卖一次股票，券商从中抽取平台费。
( 平台费和佣金，合起来就是：**==券商手续费==** )
🔥3️⃣ **融资利息**：你可以选择借券商的钱买股票，借来的那部分的钱，要给券商利息。
4️⃣ **收承销费**：==帮公司上市==，从募集资金里抽钱
5️⃣ **自营投资**：自己在交易所买卖股票(相当于个体投资者，但资金更多)
🔥6️⃣ ==**收管理费**==：管理客户的资金，按**管理规模**收费
🔥(隐形)7️⃣**换汇点差**：在券商的APP中，将港币转换为美元，有一定的小的磨损。
❗️(带🔥的是券商从你手里赚的钱，需要多加注意，减少亏钱)

### **佣金**、**平台费**
：你每买卖一次股票，付给券商的服务费，包括两部分：**佣金**(随金额变化)和**平台费**(不变)
#### 对于不同的交易类型，佣金可能不同:(以致富证券为例)
打新交易：现金认购**手续费：免费(==佣金==和==平台费==)**；**==融资认购==** 手续费： 50 港元
(融资认购  =  孖展认购)
港股交易：**==佣金==** 0.0288%，不设最低；**==平台费==** 每笔 15 港元。
美股交易：==**佣金**==0(也就是所谓的**一世免佣**)；**==平台费==** 每股 0.008 美元，单笔最低 0.99 美元。
#### 对于不同的交易方式，佣金可能不同：
同样是==港股交易==：

| 方式     | 佣金      | 最低收费  | 平台费          |
| ------ | ------- | ----- | ------------ |
| 网上交易   | 0.0288% | 无     | **每笔 HK$15** |
| 暗盘网上交易 | 0.0588% | 无     | **每笔 HK$15** |
| 电话交易   | 0.125%  | HK$68 | 无            |
>1️⃣(明盘)网上交易：你通过APP，在手机上点的交易操作 (上市后的交易，由交易所撮合)
2️⃣**暗盘网上交易**：(上市前的交易，叫做暗盘交易，由券商内部撮合，只在内部系统交易)
3️⃣电话交易：打电话给券商，让交易员帮你操作，而不用自己操作。
